# Discord LFG Bot

Бот для поиска тиммейтов в Valorant и CS2.

## Возможности
- Слэш-команда `/lfg` с выбором режима и количества игроков
- Кнопка «Присоединиться» с живым обновлением состава
- Автоматическое закрытие набора при заполнении
- Валидация параметров средствами Discord API

## Настройка
Скопируйте `.env.example` в `.env` и заполните:
```
DISCORD_TOKEN=токен из Developer Portal
GUILD_ID=ID вашего сервера
```
## Стек
Python 3.14, discord.py 2.7
